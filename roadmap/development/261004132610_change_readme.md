## 3. READMEの記載内容（案）

- 言語: 日本語（利用者が日本語話者のため）
- アプリ名と概要（スペック0章の目的。オンデマンド授業のpptx/ppsxから、音声1本・スライドPDF・タイムスタンプJSONを生成する）
- 主な機能と出力ファイル（`<basename>_audio.*`・`<basename>_slides.pdf`・`<basename>_timestamps.json`）
- 非スコープ（自動監視・外部アップロード等を行わないこと）
- 動作環境: Windows（主対象）。macOS版はビルドのみで、変換動作は保証外（imple 9章）
- 前提ソフト: ffmpeg・ffprobe・LibreOffice（soffice）を利用者が別途インストールする
- 使い方: リリースからの入手 → `app.settings.json` を exe と同じフォルダに置く（`app.settings.example.json` を元に作成）→ ファイルをドロップして実行
- 開発者向け: 必要なツール（bun・Rust）、`bun install`、`bun run tauri dev`、テスト、`bun run tauri build`（スペック12章）
- リンク: `CHANGELOG.md`
- 書かないもの: `samples/` の実ファイルの内容、個人環境の絶対パス、`roadmap/` の内部手順
