## 経緯

W10-8（macOS 版のアイコン確認）で、ユーザーから次の2点の指摘があった（261008）。アイコン自体は判別できるため、W10-8 は完了とした。

1. **macOS のアプリアイコン**: Windows と共通のマスターSVGから `tauri icon` で生成しているため、macOS Big Sur 以降で標準の形（余白を取った角丸四角形）になっておらず、Dock・Launchpad で浮いて見える。macOS Tahoe 以降の Liquid Glass のアイコンにも対応していない
2. **初回の導入（Windows・macOS 共通）**: インストール・配置しただけでは `app.settings.json`・ffmpeg・soffice がなく動作しない。スペック v4 のとおりだが UX が悪いため、インストーラーで自動化するのが望ましい

## 今後の対応（未着手）

どちらも本修正の範囲外で、着手する場合は仕様変更として change を作成して承認を受ける。

- インストーラーでの前提ソフトの導入と `app.settings.json` の作成の自動化。スペック v4 の前提（ffmpeg・LibreOffice は利用者が事前にインストール、パスは設定ファイルで指定）と、設定ファイルの配置場所（5.2）を変えることになる。ffmpeg・LibreOffice を同梱・自動取得する場合は、それぞれのライセンス（GPL/LGPL・MPL）への対応も検討が要る
- macOS 向けアイコン: マスターSVGは確定事項のため変えず、各OS・形式への展開（委任事項）として macOS 用の原本（角丸四角形と余白をつけたもの）や Liquid Glass のアイコンを用意する方法が考えられる。マスターSVGそのものを変える必要がある場合は仕様変更となる
