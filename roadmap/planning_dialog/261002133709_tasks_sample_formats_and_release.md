  - 依存: T2-1

  - 実施メモ:

      - `validate` は、3つの実行パスの実在（フォルダの場合は「ファイルではありません」）と `silentSlideDefaultSec >= 0` を確認し、問題をすべて返す。`silentSlideHandling` の値は parse の段階で確認する

      - 不明な項目は無視する（項目名を打ち間違えた場合は、必須項目なら「〜がありません」で検出され、省略可能項目なら既定値になる）
